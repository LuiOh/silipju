# 실입주

세안고(세입자를 낀 채 파는 매물)를 걸러낸 실입주 아파트 매물을 대출·필요 현금·통근시간과 함께 보여주는 개인용 로컬 앱입니다. 매물은 크롬 확장프로그램이 네이버페이 부동산 지도에서 모아 오고, 모든 데이터는 이 컴퓨터의 SQLite 파일 하나(`.data/silipju.db`)에 저장됩니다.

## 필요한 것

- Node.js 20 이상
- 크롬(확장프로그램용)
- 별도 DB 서버나 도커는 필요 없습니다.

## 새 PC에서 처음 세팅

```bash
git clone <저장소 주소> silipju
cd silipju
npm install
npm run dev -- --port 3210
```

브라우저에서 http://localhost:3210 을 엽니다. 처음 켤 때 `.data/silipju.db`가 자동으로 만들어집니다. 확장프로그램이 `http://localhost:3210`으로 데이터를 보내므로 포트는 3210을 쓰세요(다른 포트를 쓰면 확장 팝업에서 앱 주소를 바꿉니다).

### 확장프로그램 설치(한 번만)

1. 크롬 주소창에 `chrome://extensions`를 열고 오른쪽 위 개발자 모드를 켭니다.
2. '압축해제된 확장 프로그램을 로드합니다'를 눌러 이 프로젝트의 `extension` 폴더를 고릅니다.
3. 앱 화면을 새로고침합니다.

코드를 새로 받아 `extension` 폴더가 바뀌었으면 `chrome://extensions`에서 실입주 수집기의 새로고침(↻)을 누르고 앱 화면도 새로고침합니다.

### API 키(선택)

앱 상단 'API 설정'에서 넣고 바로 연결 테스트를 할 수 있습니다. 키는 `.data/silipju.db`에만 저장되고 깃에는 올라가지 않습니다. `.env.local`에 넣어도 됩니다(`.env.example` 참고).

- TMAP: 실제 대중교통·자동차 통근시간
- 카카오 로컬: 직장·장소 검색, 상세 화면의 주변 학교
- 국토부(data.go.kr): 실거래가·전월세, 세안고 판별 보조
- Anthropic(Claude): 상세 화면의 AI 동네 브리핑(평판·입지·배정 초등학교, 누를 때마다 과금)
- 금감원 금융상품 한눈에: 은행 상품별 공시 금리(선택)

현행 대출 금리(보금자리론·디딤돌·신생아 특례·은행 평균)와 보금자리론·디딤돌 안내문의 핵심 규정 문구는 키 없이 공식 공시에서 하루 한 번 자동으로 가져옵니다. 상단 '규정 기준일'에서 언제 가져왔는지 보고 다시 가져올 수 있습니다.

## 매일 쓰는 순서

1. `npm run dev -- --port 3210`으로 앱을 켭니다.
2. 상단 '실매물 수집'에서 시·구를 고르고 '오늘 매물 수집하기'를 누릅니다. 새 창에서 네이버페이 부동산 지도가 열리고 칸을 옮겨 가며 매물을 모읍니다. 끝날 때까지 그 창을 닫거나 최소화하지 마세요(수원·성남·용인 기준 약 1시간). 중간에 멈췄으면 같은 화면이나 확장 팝업에서 '이어서 수집'을 누릅니다.
3. 수집이 빠짐없이 끝나면 그 지역에서 이번에 보이지 않은 매물(팔렸거나 내려간 매물)은 자동으로 정리됩니다.
4. 왼쪽에서 조건(가격·면적·층·세대수·직장·가구·대출)을 바꾸고 검색합니다. '정렬·가중치'에서 역세권·재개발 호재·학군 등의 비중과 역세권에서 뺄 노선(예: 에버라인, 경강선)을 고를 수 있습니다. 매물을 누르면 대출 상품별 한도, 통근 경로, 실거래가, AI 동네 브리핑을 볼 수 있습니다.

## 데이터 옮기기·백업

모든 데이터(매물·세대수·API 키·현행 금리·AI 브리핑)는 `.data/` 폴더에 있습니다. 다른 PC로 옮기려면 앱을 끈 뒤 `.data` 폴더를 통째로 복사합니다. 앱이 켜져 있으면 최근 변경이 `silipju.db-wal`에 남아 있을 수 있으니 꼭 끄고 복사하세요.

## 명령어

```bash
npm run dev -- --port 3210          # 개발 서버
npm run build && npm start -- -p 3210  # 배포용 빌드로 실행
npm test                            # 테스트
npm run batch -- stats              # DB 현황과 최근 배치 기록
npm run batch -- prune --days 21    # 21일 이상 다시 보이지 않은 매물 정리
npx tsx scripts/build-transit.ts    # 지도 지하철 노선 데이터 다시 만들기(Overpass)
npx tsx scripts/build-schools.ts    # 학군 점수용 초·중학교 위치 데이터 다시 만들기(Overpass)
```

## 주의

- 네이버 이용약관은 자동 수집을 금지합니다. 본인 확인용으로 하루 한 번 정도만 쓰세요. 네이버가 요청을 막으면(429) 수집기는 바로 멈춥니다.
- 대출 한도·세금은 규정을 단순화한 추정치입니다. 실제 한도는 KB시세·감정가·은행 심사에 따라 다릅니다.
- AI 브리핑과 배정 초등학교 정보는 틀릴 수 있으니 학구도안내서비스(https://schoolzone.emac.kr/)에서 꼭 확인하세요.
